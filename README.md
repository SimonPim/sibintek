# Система управления заявками СИБИНТЕК

Django-приложение для учёта сервисных заявок.

## Функции

- Создание и редактирование заявок
- Назначение исполнителей
- Фильтрация и поиск
- Экспорт в Excel и PDF
- Разграничение прав доступа
